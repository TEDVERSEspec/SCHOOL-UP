Timetable

It builds itself.

Tap "Generate for me". SchoolUp reads your teachers, their subjects and their classes, then lays out the week. Change any slot by hand afterwards.

  • Follows the Nigerian school day: P1 to P3, short break, P4 and P5, long break, P6 and P7, recess
  • Never puts a teacher in two classes at once
  • Set your own start time and period length

Class chat

Chat that stays safe.

Each class gets its own chat. Teachers can read every message, so students keep it kind and about school, and parents can trust it.

  • One chat per class, with teachers marked clearly
  • Post assignments and notices in the same place
  • Students ask questions where the teacher already is

Student IDs

An ID a child can remember.

Register a student and SchoolUp makes the ID for you: class, first name, then a short code. Try it with any name.
